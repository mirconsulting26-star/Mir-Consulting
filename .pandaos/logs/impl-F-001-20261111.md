**Changes:**
- `frontend/scripts/generate-sitemaps.js`: added a build-time generator that
  fetches public posts, case studies, videos, and team profiles from the
  configured backend; it writes XML URL sets and a canonical sitemap index.
- `frontend/package.json`: invokes the generator after the React production
  build.
- Empty content collections are omitted from the index rather than emitting
  empty child files.

**Verification:** Production build succeeded with the configured backend and
canonical site origins. Generated sitemap index and all 3 non-empty child
files parse as XML: pages (23 URLs), posts (8), and team (1). All URLs use the
canonical host, all index targets exist, and no lastmod/changefreq/priority
values are emitted. Case-study and video maps were omitted because their
public endpoints returned no URLs. The built sitemap and robots directive
were checked, and a local HTTP server returned the built index as HTTP 200
with an XML content type. Render's deployed response remains unverified until
the user deploys.
**Issues encountered:** A plain local build without `REACT_APP_BACKEND_URL`
fails clearly; validation was rerun with the backend URL already configured in
`render.yaml`. The backend endpoints responded successfully.
**Time:** 2026-11-11
