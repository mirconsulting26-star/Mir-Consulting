# Data Visualization

## Choose the visual from the question

- Use a table for exact lookup and a small number of values.
- Use lines for ordered time trends.
- Use bars or dots for comparisons across categories.
- Use histograms, box plots, or density plots for distributions.
- Use scatterplots for relationships between quantitative variables.
- Use small multiples when overlapping series would become hard to read.

Avoid pie charts with many categories, dual axes without a compelling reason, decorative three-dimensional effects, and maps when geography is not part of the question.

## Preserve analytical integrity

Show units, denominators, date ranges, filters, sample size, and source. Use a zero baseline for bars unless a clearly disclosed exception is necessary. Do not truncate axes to exaggerate change. Show missing periods rather than interpolating them silently. Encode uncertainty when it affects interpretation.

## Make the result readable

Lead with a declarative title that states the supported takeaway. Label directly when practical, order categories intentionally, and keep color reserved for meaning. Use a colorblind-safe palette and ensure the result remains understandable without color alone. Provide alt text or a textual summary for essential visuals.

## Deliver the artifact

Include the visual or table, the takeaway it supports, the metric definition, and a short methodology note. If the available tools cannot render the chosen visual, provide a precise chart specification or a clean summary table without fabricating an image.
